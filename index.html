隐私说明

本说明适用于《暗影忍者》游戏内未启用广告、使用本地存档的内部测试版本。

适用范围：本说明仅对应目前准备中的本地存档、游戏内未启用广告的内部测试版本。联网版本、广告接入和正式发行版本的数据处理可能不同，届时将另行核实并更新；平台宿主的实际数据处理仍待核实。

更新日期：2026 年 11 月 3 日

一、游戏内保存的信息

为了保存和恢复本机游戏进度，测试版会在设备或运行容器的本地存储中保存随机生成的游戏玩家标识、存档创建及游戏时间、角色与关卡进度、道具和装备、游戏资源、任务及奖励领取记录、战斗状态和操作记录等。音乐、音效和震动设置也保存在本地。该玩家标识由游戏在本地生成，并非平台账号。

测试版游戏逻辑中的存档操作在本地进行；游戏源码未接入在线账号，也未将上述存档发送至游戏开发者的服务器。游戏资源的加载、运行容器和平台自身的网络活动不在这一结论范围内。

二、广告、支付和分享

本测试版未启用广告及广告奖励，也不提供支付。邀请和录屏分享任务在测试版中不可用。若后续版本接入这些能力，将在使用前更新相应说明。

三、保存时间与删除

本地存档通常保留在设备或运行容器中，直至用户清除相应数据或容器自行清理。浏览器中运行时，可通过浏览器的站点数据设置清除本游戏的数据；其他容器的清除方式以相应平台说明为准。清除本地数据可能永久丢失进度和设置。游戏没有接入在线账号或游戏服务器的跨设备恢复功能；平台或设备是否提供备份与恢复，请以其实际功能为准。

为避免多个页面同时写入存档，部分浏览器还可能在本地保存临时存档锁和随机实例标识。游戏会在正常关闭时尝试移除该锁。

四、平台及本网页

游戏使用 Cocos 引擎，并拟在 OpenPaaS 或其合作平台的运行容器中测试。平台和运行容器可能为加载游戏、安全与运行服务处理网络地址、设备或其他信息；平台、引擎及其运行时实际处理信息的类别、目的和保存时间尚待核实。请同时查看您实际使用的平台提供的隐私说明。本说明不替代平台自身的隐私政策。

本网页由 GitHub Pages 托管。GitHub 可能处理访问者的 IP 地址等网络信息；详情可参阅 GitHub Pages 官方说明 和 GitHub 隐私声明。本页面不含输入表单，也未添加分析或广告脚本。

五、联系与更新

如对测试版数据处理或本说明有疑问，可通过 GitHub 问题反馈入口留言。该入口为公开页面，请勿提交姓名、联系方式、设备标识、游戏存档或其他个人信息。目前用于处理个人信息请求的私密联系渠道仍在确认。

开发者的公开运营名称、可私密联系的渠道及平台宿主的数据处理细节仍在确认。正式发布前，将结合实际发行版本补充完整的政策、联系方式及适用语言版本，并核实所需告知和选择方式。
